# M-LLM 知识工作台验收样例

整车车辆制造软件版本必须可追溯。生产线在软件刷写、配置下发、版本校验和结果回传过程中，应保存车辆、工位、软件包、版本号、执行结果和时间戳等证据。

车辆制造过程中的软件一致性不能只依赖人工确认。知识工作台需要同时提供关键词检索和本地向量检索，并通过 Hybrid 融合找到“车辆软件制造”“版本追溯”“工位证据链”等相关内容。

当知识文件发生变化时，旧的向量索引必须失效并重新构建；未完成全部有效向量索引之前，Hybrid 状态不得显示为可用。

所有验收数据保存在设备本地 SQLite 数据库中，应用重启以后，文档、切片和已经构建的向量索引仍然可以继续使用。
