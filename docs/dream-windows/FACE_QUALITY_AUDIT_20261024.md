# 2026-10-24 人物效果复核

用户指出人脸不像、贴脸感明显及越修越差。本次按保存的参考图、原图、对齐预览、第一轮及第二轮逐张复核；流程成功不等于视觉效果验收。

## 已确认的问题

1. 对齐初始化使用五个位置点拟合相似变换，再通过目标检测框的椭圆贴入参考脸。没有源脸轮廓分割、头发/耳朵遮挡或光照匹配。较小的五点拟合误差不能证明下颌、脸颊与头部轮廓匹配；贴脸问题在扩散重绘之前已存在。
2. 原实现每轮都以最初底图作为合成背景。软蒙版边缘会再次混入旧脸：忽略取整与缩放时，参考图贡献从 `s*M` 依次下降到 `s*M^2`、`s*M^3`。同时采样蒙版把低于 128 的羽化带排除，边界未获得同等重绘机会。
3. 两轮都重绘整个脸部区域，眼、鼻、嘴没有独立保留约束。“融合”“细化”是流程名称，不代表实际只调整光照或增加正确细节。已保存的第二轮有新增纹理，不能称为质量提升。

## 本轮修复及验证

只修改已由对照复现的合成错误：每轮把补丁合成到上一阶段结果，不再合成到最初底图。新测试分别覆盖普通两轮和参考对齐两轮：模型返回不变补丁时，羽化区域也必须保持不变。两条测试修改前失败，修复后通过；相关引擎及对齐测试 38 项通过。

在实际保存图上绕过扩散和缩放，旧合成方式改变了 35,385 个羽化区像素，修复后的方式改变 0 个像素。这证明修复了无修改输入也会退化的合成错误，不证明新一轮扩散的画质合格。

另外做了真实 GPU 的 VAE 编解码对照，不进行任何去噪。单独缩放和 VAE 重建未复现已保存第二轮那种明显新增纹理；因此不能把该纹理全部归咎于图像压缩或缩放。像素差异指标仅用于隔离处理阶段，不是人物相似度指标。

## 尚未解决

参考脸与底图头部的结构匹配、脸缘和遮挡处理、重绘对五官的改写，以及何时应放弃第二轮都仍待改进。当前没有证明任意姿态的角色一致性，不能以这次合成修复宣称整体人物效果修复完成。

下一阶段应先在固定底图上分离五官保留区与边缘融合区，验证轮廓/遮挡匹配后再执行边缘融合；比较结果后才决定是否继续重绘。继续提高全图权重、增加步数或自动追加整脸重绘没有得到本次证据支持。
