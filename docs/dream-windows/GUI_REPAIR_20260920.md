# 浏览器 GUI 修复与验证

验证时间：2026-09-19 深夜至 2026-09-20（Asia/Shanghai）。

## 本轮修复

- 补齐生成页提示词、预设、高级标签的深色主题样式，统一可读字号和控件尺寸。
- 修复生成、模型、历史、实验室、设置的响应式布局；模型检查器回到独立栏位，窄屏模型搜索与筛选不再横向溢出。
- 窄屏提供六项有文字的顶部导航，生成按钮吸底；移除阻断吸底的主内容区嵌套滚动样式。
- 保留已有的生成页常驻机制，不因切换导航卸载或取消生成。
- 显微镜运行记录选择器在所有子页可用，支持刷新以及切到最近的 H7/潜空间兼容记录。
- H7 增加 Token×步骤聚合、逐层对比、原图叠加、区域框选/数值调整、按需读取的区域 Top 5 Token。
- Token 输入权重不再被描述成注意力强度。聚合表明确使用已采集层的峰值均值，区域统计使用原始注意力值。
- 专家页原始记录可折叠、语法着色、复制和下载。
- 设置页的文字大小、密度、减少动态效果、历史自动刷新策略可以保存到当前浏览器。
- 历史默认刷新周期由 5 秒调整为 30 秒，页面不可见时不轮询，支持关闭自动刷新；修复键盘导航绑定时机。
- 系统诊断取消硬编码的健康结论：未检测项明确显示未检测，不把 CUDA 可用等同于所有组件正常。
