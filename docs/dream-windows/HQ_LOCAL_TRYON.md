# HQ 素材接入 Dream 本机人物工作流

此功能在本机浏览器直接使用。HQ Cloudflare Worker 继续只提供自有 R2 原图和既有授权；不创建云端生成队列，不轮询领取任务，也不上传生成结果。

## 使用顺序

打开 `http://127.0.0.1:8766/?view=hq-tryon`。

1. 选择人物原图。可以绑定现有 FaceID 人物档案，但档案参考与所选原图必须一致，不能静默替换人物。
2. 在完整 R2 图库搜索、分类或翻页，按白模预览选择姿势与视角。当前 1,439 个姿势都有对应深度图。
3. 点击「本机生成」后，Dream 按所选白模的编号与原图 SHA-256 查找深度图，将它送入原有 A/B/C 采样流程。缓存缺失时只读取该姿势的 R2 对象。确认区显示所选姿势的控制方式。「套用 A/B/C 定稿参数」可恢复 768×1152、30 步、种子 20261104 和可选修脸强度 0.35。
4. 按需启用原有可选修脸。真人路线沿用身份回贴与细节修复；修脸前底图单独保留，失败需显示原因。
5. 查看底图与结果，再从原有独立精修工作台执行下一轮或回到原图。精修不是自动质量优胜选择。
6. 确认构图与脸形后，可在同一工作台执行“2倍清晰增强”。生成独立版本，不覆盖原图；增强版本可选择、查看与下载，后续精修须回到增强前版本。

尺寸预设支持 512×768、640×960、768×1152 及横版，总像素最多 884736。首次打开时，仍使用旧出厂参数的草稿会采用新的定稿参数。自定义参数、已选人物和正在查看的任务会保留。

2026-11-02 已从正式网页选择人物、SXY-0004 和 P001 仰拍坐姿，生成并下载 768×1152 的 PNG。三路输入各记录到 30 次真实采样调用，浏览器下载与服务端成片的 SHA-256 一致。发布验收实跑的是 A 场景。B 所用另一张深度图通过定稿采样输入校验。这版沿用定稿的服装还原效果，部分鞋履和配件仍有偏差。

完整图库恢复时已逐页核对 1,439 个姿势的编号与 R2 原图哈希，覆盖 26 个分类。此次深度库发布后，1,439 张原始深度图（24,046,098 字节）均已上传到独立前缀并逐张回读核验。每个姿势都校验了对应 R2 白模的原图尺寸。

本机浏览器实测「站立・双手撩发 · 斜侧」在空缓存下取得对应的 R2 深度图。实际输入 ControlNet 的张量与该图一致，完成 30 步采样并下载 768×1152 PNG。原插件的同号取图调用仍返回白模 PNG，发布前后三个代表姿势的白模文件哈希和原 MCP 工具签名逐项一致。此次版本更新位于 Dream 仓库。

预览显示实际文件尺寸，支持适应窗口、100% 原始尺寸和打开原图；200% 只是显示缩放，不增加细节。“2倍清晰增强”是单独运行本地模型，不是浏览器缩放，也不保证恢复缺失的真实细节。

实际三组验收、限制和测试范围见 [2026-11-02 验收记录](HQ_LOCAL_ACCEPTANCE_20261102.md)。当前流程可运行，人物外观与服装细节的视觉总评仍为 PARTIAL。

连续姿势失败、原生高清和独立清晰增强的修复见 [同日后续复测](HQ_REPAIR_20261102.md)。

首期三图组合使用已有 Realistic Vision V5.1 + FaceID Plus V2 配套。新增服装、姿势条件不等于所有底模都已兼容；现有 Cyber、动漫视觉、五官保护及普通人物功能保持原有能力边界。服装图进入推理并不保证品牌标识、纹理或剪裁逐像素还原。

## 本机服务

沿用桌面 `启用可选修脸.cmd`，或执行：

```powershell
& 'C:/Program Files/PowerShell/7/pwsh.exe' -NoProfile -File E:/Dream/repo/scripts/start_dream_web_background.ps1
```

只在回环地址提供服务。重复启动应复用原服务；不要启动公开 FastAPI、ComfyUI 或任意命令接口。停止前取消未完成任务，等待已有工作进程退出。重新启动后读取本地任务记录，不自动重跑中断的生成。

需要前台运行时可用 `scripts/run_dream_web.ps1 -Port 8766`；在该服务窗口按 Ctrl+C 停止。后台模式先关闭任务提交页面，再运行以下命令。停止脚本会核对本项目服务归属和活动任务，无法确定或仍有任务时拒绝停止，不处理其他项目进程。

```powershell
& 'C:/Program Files/PowerShell/7/pwsh.exe' -NoProfile -File E:/Dream/repo/scripts/stop_dream_web.ps1 -CheckOnly
& 'C:/Program Files/PowerShell/7/pwsh.exe' -NoProfile -File E:/Dream/repo/scripts/stop_dream_web.ps1
```

重新运行启动器并点击页面“刷新图库与任务”即可重连。

## 配置和人物授权

`E:/Dream/data/hq/config.json` 仅由本机后端读取，设置自有 Worker origin、短期会话文件及本地条件配置。人物运行环境、模型和修脸权重沿用 `E:/Dream/data/identity/runtime.json`。原有模型继续从既有安装位置读取；新增配置、缓存和审计放在 E 盘。

可选清晰增强在同一人物运行配置中增加 `upscaleModel`，指向本机已有 `RealESRGAN_x4plus.pth`，其 SHA-256 随每个增强版本记录。使用配置中 `python` 对应环境的 PyTorch、Spandrel 和 Pillow，不依赖网页服务解释器安装推理包。能力检测不加载模型或初始化 GPU；结果短期缓存，配置／模型／解释器文件改变即失效。推理进入现有串行 GPU 队列，用 128 像素分块、32 像素上下文，4倍模型输出降采样为严格2倍；不再加载底模、换脸模型或参考照。未配置或组件缺失时不显示可用增强模式。

人物授权复用已授权 Cloudflare 连接器和私有 R2 会话机制。原始 Bearer 仅保存在当前 Windows 用户和 SYSTEM 可读的本机凭据文件中；R2 只保存会话的 SHA-256 与有效期。浏览器、Git、普通日志和推理进程不接收会话或 Worker 主密钥。无公共免鉴权签发入口。

授权过期时需重新签发短期会话。下载阶段必须仍获授权；成功下载并校验的输入可在本机执行，不依赖十分钟单图 grant 排队存活。不能用缩略图、截图或原素材外站替代失败的 R2 原图。

## 接口与证据

新增接口均在本机 `/api/hq`：`status`、`catalog`、`asset`、`jobs`、单任务状态、`cancel`、三角色 `inputs` 和 `result`。Cloudflare 原有 MCP 三个工具不承担本机执行。

本机任务使用持久幂等键。网络重试和重复点击复用同一创作动作；参数变化或明确点击失败／取消任务的“按相同设置新建重试”才创建新动作。手动重试保留旧任务，生成新的请求编号。重启中断不能自动重跑，失败也不能被接口成功回执掩盖。

每次记录三图角色、原始 ID、SHA-256、尺寸，预处理与条件对应关系，实际模型文件、参数、种子，送入模型的条件绑定、阶段耗时与成片 SHA-256。人物、姿势和服装必须使用独立输入。人物原图、作品、精修版本及含私人图像的验收文件均不进入 Git。

启用完整深度库时，先停止空闲服务并运行 `scripts/enable_hq_paired_depth.ps1` 核验模型。在项目目录运行以下命令，使用本机已有的 Wrangler 授权从自有 R2 获取并校验完整包。

```powershell
npm.cmd install --prefix E:/Dream/tools/hq-depth-r2 --save-exact wrangler@4.156.0
python scripts/install_hq_depth_library.py --activate
```

传入 `--bundle <已回读的 bundle.zip>` 可离线安装。传入 `--index-only` 可只安装索引，在首次生成时按需补齐缓存。发布记录与 SHA-256 随 Dream 代码保存在 `config/dream/hq-paired-depth-v1/full-release.json`。深度图独立存放在 `hq-tryon-assets/dream-depth/v1/`，本机缓存位于 `E:/Dream/models/hq/depth-library/`。配置有变动时安装器会输出备份路径。构建前端并启动服务后，`/release.json` 显示 `dream-hq-r2-depth-library-20261102`。

原 HQ 选材器与 MCP 的 `get_tryon_asset({kind:"pose",id})` 继续读取白模 PNG。深度选择、补取和使用回执仅在 Dream 本机生成流程内执行。

## 排障和回滚

- 服务离线：使用原启动器；先核对端口监听归属，不停止其他项目服务。
- 人物授权失效：重新签发短期会话，之后刷新授权状态。公开素材不需要人物会话。
- 原图校验失败：保留错误和已下载证据，不改用缩略图。已终止任务需明确创建新动作，不能隐式再推理。
- 保存的姿势可直接复用。模型文件缺失时页面会提示对应姿势的模型状态。骨架提取失败时可在任务详情查看原因，遮挡和多人图可能不适合现有单人骨架模型。
- 显存不足：终止当前任务并确认 CUDA 工作进程退出；不自动同时启动第二个生成或无限重试。
- 修脸／精修效果不满意：查看原图，按原有工作台保留版本、选择版本；不覆盖参考照或原始作品。
- 清晰增强不可用：检查人物配置中的模型路径及其工作解释器；增强失败不会把原图作为成功结果发布，也不会自动覆盖当前选择。增强成片不可重复放大；需要改脸或光照时先选择原图或增强前版本。
- 回滚时先停止空闲服务，将启用脚本保存的备份恢复到 `E:/Dream/data/hq/pipeline.json`，再使用上一个版本的后端与前端启动服务。原有作品和人物档案沿用现有存储。

验收必须分别记录：软件测试、实际三图绑定、可查看下载成片、人物外观、服装特征、姿势与全身构图。上述接口或文件存在本身不是视觉 PASS。
