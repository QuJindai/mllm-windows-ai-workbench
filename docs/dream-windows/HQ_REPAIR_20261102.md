# HQ 连续失败与清晰度修复 · 2026-11-02

## 已定位的原因

用户的两次失败均发生在采样前，错误为 `POSE_LOW_CONFIDENCE`，不是此次任务发生了 CUDA OOM。DWPose 将白底线稿的原边界外扩后，用黑色填充仿射采样范围；坐姿的右膝和斜侧举手的左肘分别只有 0.266893、0.292779，未通过原有 0.3 门槛。

改为先保持原解析；仅在符合严格白底条件且已有至少六个可靠肢体关节时，尝试一次原画框以外白色留边，仍要求十二个主要关节全部达到 0.3，并要求原可靠关节位移不超过原图对角线的5%。不混合两次坐标、不插值关节、不降低门槛。两组真实 CPU 输出最低分分别变为 0.432610、0.327575；原先成功的两个正面姿势结果和骨架哈希不变。

原 HQ 限制512×768、没有整图清晰增强；全身图的脸部所占像素少，原有修脸贴回后仍是这个尺寸。旧 ComfyUI 工作流支持更大的原生尺寸和最后一步可选增强，本次恢复这些能力，继续通过既有 `IdentityService → IdentitySession → 原有可选修脸 → 独立精修版本`，未创建另一套生成器。
