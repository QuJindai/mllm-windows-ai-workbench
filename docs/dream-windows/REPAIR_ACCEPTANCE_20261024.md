# 2026-10-24 本机修复与验收边界

## 硬件监控与生成入口

硬件监控采样失败不再单独禁用普通生成按钮。保留最后一次有效采样时，必须同时标明采样时间和过期状态；提交请求后仍由后端完成真实生成预检。模型加载、参数校验和正在运行的队列限制继续生效。

后端对采样失败记录固定类别和异常类型，不记录驱动 stderr、完整命令或本机路径。失败缓存仍返回 503，不把未知状态伪装成正常状态。

## 启动入口

`npm run web` 和 `npm run web:build` 使用 PowerShell 7 的 `pwsh -NoProfile`。前台脚本和后台启动器默认端口统一为 8766。

2026-10-24 本机在独立端口 18766 实测后台启动器：首次创建服务，第二次启动复用同一 PID。测试结束关闭其自建进程。正式服务在确认普通任务、人物任务和人物批次均无待处理记录后重启，页面、健康接口和实时硬件采样回读成功。
