# 场景预设与本机验收（2026-10-28）

“生成”和“人物创作”的提示词区域新增古风、女帝、公主、科幻四个入口。选择写实或动漫插画，再点击场景，填入该场景的正、负提示词。默认模板以成年女性半身创作为起点，用户可修改人物、服装、背景和姿态。

## 使用行为

- 只替换提示词，保留当前人物档案、参考照片、底模、身份强度、种子、尺寸、步数、批量张数、显微镜和可选修脸设置。
- 支持撤销最近一次场景替换；手动改写提示词后不再显示过期的撤销入口。
- 模型切换会更新推荐画风，但不会自动覆盖提示词或替换模型。
- 正在生成时锁定场景按钮。写实或动漫提示词需与所选模型相匹配。
- 现有草稿机制继续保存应用后的提示词，切换页面不会丢失。

## 验证结果

- 前端完整测试：39 个文件，596 项通过；TypeScript 检查与 Vite 生产构建通过。
- GUI 验证：场景应用、动漫提示词切换、撤销、人物参数保留、生成中禁用、切换页面保留草稿。
- 在 1600、1024、640 像素窗口检查页面，无横向溢出。
- 实测使用同一个本机人物档案、Realistic Vision V5.1 + FaceID Plus V2；512×768、28 步、CFG 5.5、身份强度 0.82、结构强度 0.90、配套 LoRA 0.55。
- 每场景使用种子 20261028 和 20261029 各生成一张；中间预览每 5 步，关闭显微镜与修脸。四类最终样张共 8 张，另保留科幻首轮 2 张，总计 10 张真实输出。
