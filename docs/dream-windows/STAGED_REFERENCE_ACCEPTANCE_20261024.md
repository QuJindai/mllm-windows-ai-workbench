# 2026-10-24 分阶段人物参考管线

## 已实现

视觉参考模型的“生成后修脸”新增可选参考脸对齐、融合强度和一至两轮局部处理。默认仍为原有单轮局部重绘；切换对齐模式时第一轮去噪设为 0.25，第二轮固定 0.15。第二轮接着第一轮处理，不重新生成整张图。

原图、对齐预览、第一轮融合和可选第二轮均有独立产物。结果页可切换查看，并显示每轮实测步数及耗时。每个阶段保留任务、参考和参数绑定；失败时原图保留。五点对齐误差只表示几何拟合，不是人物相似度。

阶段图片按任务隔离并原子发布。取消或恢复清理限于本任务；删除结果包含阶段产物。单个中间图缺失不再阻止查看其余完整图或原图。恢复任务也重新校验阶段凭据，缺失或不匹配时不显示修脸成功。

## 验证记录

- 前端：35 文件、526 项通过；TypeScript 与生产构建通过。默认高并发测试曾出现超时，使用 2 workers、保持原超时后全量通过。
- 后端：首次全量 1308 项通过、2 项跳过；复核修复后 315 项相关测试通过。CPU 测试与真实 GPU 生图分开记录。
- 独立复核指出并修复 3 项问题：取消遗留临时文件、缺失阶段阻挡原图、前后端阶段凭据校验不一致。再次只读复核无剩余重要问题。
- NOOB 隔离对照：同一底图比较单纯重绘、参考脸对齐后融合以及第二轮细化。局部各轮约 13–23 秒，蒙版外像素逐像素相同。第二轮没有稳定优于第一轮，故不默认开启。
- 正式 Cyber 视觉参考管线：768×768、30 步实际完成。第一轮 7 步 / 31.276 秒，第二轮 4 步 / 21.170 秒；完整可选修脸 56.315 秒。整次冷启动任务约 370 秒，推理阶段合计 277.374 秒；这些局部耗时不代表全流程仅需几十秒。峰值已分配显存 2176 MiB，峰值保留 2192 MiB。
- 同一实测任务的原图、最终图和三个阶段端点均读取成功；所有阶段与最终图在蒙版外的像素均和原图完全相等。人工查看图片后，第二轮出现更强纹理，不能据此宣称质量提升。
- 本机 8766 服务及构建资源 HTTP 回读成功；五份现有人物档案和运行配置与工作前哈希一致。
- 浏览器人工式操作验收未完成：Windows 工具无法可靠确定浏览器地址，已停止界面操作。组件、构建、HTTP 和 GPU 测试不代替 GUI 验收。

## 仍需迭代

对齐初始化可保留更多参考脸特征，但侧脸、脸缘过渡、光照和画风一致性仍需优化。多人、检测失败或姿态差异太大时保留原图并返回失败原因。当前是在一次任务内按阶段执行、事后对照；尚未实现历史图片的独立修脸工作台或每轮人工确认后再继续采样。

此功能接入已有视觉参考模型。NOOB 仍在隔离实验；Illustrious 搭配通用 Plus Face 的旧画质门槛未解除。流程通过不代表精确角色一致性已达标。

私人参考图、人物档案、输出及特征缓存仅保留在本机，不提交到 Git。
