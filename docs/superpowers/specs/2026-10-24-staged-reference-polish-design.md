# 分阶段人物参考与修脸

用户要求优化整条管线，逐步收敛，不再要求一次生图同时满足构图、画风和人物特征。沿用现有浏览器、串行 GPU 队列、可选修脸、原图保留及结果对照。

## 本轮实现

1. 先生成构图与画风；原始结果继续保留。
2. 可选“参考脸对齐”：用当前所选参考图的五点位置做不镜像的相似变换，把参考脸初始化到目标脸区域。仅使用检测位置，不新增生物识别特征；位置不可靠、多人或姿态差异过大时保留原图并报告失败。
3. 进行蒙版内低强度重绘，融合画风和光照。衣服、背景等蒙版外像素保持原样。
4. 可选第二轮轻量细化，使用第一轮结果，不重新生成全图。第二轮固定 0.15 去噪；每轮有真实进度、耗时与完成记录。

原“局部重绘”模式保持默认；参考脸对齐模式明确可选，会使用参考图的脸部像素再做局部融合，不调用身份向量换脸模型或 GFPGAN。此改动先应用于已有视觉参考模型，NOOB 仍作为隔离实验，不因单图通过而解除旧 Illustrious + Plus Face 的禁用。

## 方案取舍

- 继续提高全图参考权重：已见服装和构图被带入，不能作为主要优化方向。
- 本轮选择局部对齐初始化 + 蒙版融合 + 可选细化：复用现有模型，不新增权重下载，验证每一步是否改善。
- 角色 LoRA：保留为后续增强，不作为本轮管线优化的前置条件。

## 接口约定

请求新增 `visualPolishMode`（`redraw` 默认 / `reference-anchor`）、`visualAnchorStrength`（默认 0.95，范围 0.3–1）、`visualPolishPasses`（1 默认 / 2）。新增模式和多轮仅供视觉参考模型。原 `animeDenoiseStrength` 控制第一轮。

新流程成功凭据使用 `detailerVersion=staged-face-v2`，含 `polishMode`、`passes`（每轮 kind、denoiseStrength、steps、durationMs）；对齐模式另含 `anchorStrength` 与按眼距归一化的 `alignmentError`，后者只衡量几何拟合，不能作为人物相似度分数。旧单轮结果仍接受 `masked-face-v1`。

默认值、历史重放、模型切换、工作进程复用和批次参数校验须保持一致。失败保留原始生成图。人物档案、源照片不修改；测试图片不提交到 Git。

## 本轮边界

允许第二轮在同一任务内继续细化；保存对齐预览、第一轮融合及可选第二轮细化，以任务绑定的只读接口返回，删除图片时一并清理。用户可以在结果中切换比较，后续轮不自动等同于更好。任意历史图片的独立编辑工作台、逐轮确认后才继续采样和多视角训练是后续功能。本轮不能宣称所有姿态或精确角色一致性已经解决。
